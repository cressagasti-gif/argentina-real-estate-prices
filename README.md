# Proyecto-DATA
Proyecto de Ciencia de Datos// Base de Datos

Resumen del Proyecto: Análisis y Modelado de Precios de Propiedades en Argentina

Este proyecto se centró en el análisis de un dataset de propiedades en Argentina para identificar factores clave que influyen en el precio de venta. Utilizando Pandas y Numpy, se realizó una limpieza exhaustiva de datos, incluyendo la eliminación de duplicados y el manejo de valores atípicos. Se filtraron las propiedades en venta y en dólares, creando un subconjunto de datos para un análisis más profundo.

Se exploraron estadísticas descriptivas como promedio, mediana y desviación estándar de los precios, y se generó una nueva columna para el precio por metro cuadrado. Con Matplotlib, se visualizaron tendencias, como el precio promedio por localidad y la relación entre superficie y precio, incluyendo un sub-plot comparativo entre Capital Federal y el Gran Buenos Aires.

Finalmente, se implementó un modelo de Regresión Lineal utilizando Scikit-learn para predecir el precio de propiedades en Capital Federal basándose en la superficie cubierta. Aunque el modelo mostró una capacidad limitada para capturar toda la variabilidad (R² de 0.27), estableció una tendencia coherente y un estimado razonable, destacando la alta dispersión del mercado inmobiliario y la importancia de la ubicación. Este trabajo proporciona una base para futuros análisis y modelos más complejos.
